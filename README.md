성적 확인 및 핵심역량 분석 프로그램

주요 기능

 로그인 및 엑셀 연동
- 학생 **성명 + 학번**으로 로그인
- 외부 **Excel(.xlsx)** 파일 선택 가능
- 엑셀 컬럼 구조 자동 검증

과목별 성적 분석
- 대상 과목
  - 파이썬기초및실습
  - 영상이해
  - 알기쉬운 확률통계
- 제공 정보
  - 본인 점수 / 평균 점수
  - 본인 등급 / 평균 등급
- 시각화
  - **막대 그래프** (본인 vs 전체 평균)

핵심역량 분석 (6개 영역)

| 핵심 역량 |
|---------|
| 기초 이론 이해 |
| 개념 적용 및 구현 |
| 문제 해결 |
| 데이터 분석 및 해석 |
| 프로그래밍 활용 |
| 자기주도적 학습 및 확장 |

- 과목별 **역량 가중치** 적용
- 계산식  
```
역량 점수 = Σ(과목 점수 × 해당 과목의 역량 가중치)
```
- 시각화
  - **레이더 차트** (본인 vs 전체 평균)
역량별 맞춤 피드백
- 점수 구간 자동 분류
  - 보완 필요
  - 보통
  - 우수
- 역량별 학습 가이드 자동 제공

 총평 자동 생성
- 최고/최저 역량 분석
- 개인 맞춤 종합 코멘트 제공


엑셀 파일 형식 (필수)

기본 정보
- 성명
- 학번

과목별 점수 및 등급
- 파이썬 점수 / 파이썬 등급
- 영상이해 점수 / 영상이해 등급
- 확률과 통계 점수 / 확률과 통계 등급
